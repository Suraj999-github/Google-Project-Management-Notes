# Google Project Management Certificate: Study Roadmap and Mock Tests

A small set of static web pages for studying the Google Project Management Certificate (Coursera): an 8-week roadmap and two interactive mock tests with scoring and explained answers.

> **Disclaimer:** This is an independent, original study project. It is **not** an official Google or Coursera product, and the practice questions are **not** official assessment questions. Course names, hours, deadlines, and pass marks can change, so confirm them on the [Coursera program page](https://www.coursera.org/professional-certificates/google-project-management). The Google certificate is not a PMP credential and does not guarantee a job.

## Contents

| File | What it is |
|---|---|
| `pm-certificate-roadmap.html` | 8-week study roadmap with a weekly timetable, week-by-week plan, key notes, study habits, and a progress tracker |
| `pm-mock-test-1.html` | Mock Test 1: 50 original practice questions |
| `pm-mock-test-2.html` | Mock Test 2: 50 new original practice questions |

## Features

**Roadmap page**
- Overview of the six courses and a weekly timetable (about 10 hours per week)
- Eight weekly goals with practice-question references and "done when" criteria
- Notes on formulas, look-alike terms, Agile rules, and honest credential wording
- Printable layout and a tick-box progress tracker (resets on refresh)

**Mock test pages**
- 50 questions each: single choice, select-2, true/false, and matching
- **Check answer** scores a question and marks it correct or incorrect without revealing the reason
- **View answer** shows the correct choice and the reason
- Live score, progress bar, and timer
- **Finish** gives a total and a topic-wise breakdown (Strong, Fair, Review)
- **Reset** clears answers and the timer

Topics covered: initiation and scoping, planning and schedule, budget and earned value, risk, stakeholders and communication, teams and leadership, quality, change management, Agile and Kanban, closure and career.
